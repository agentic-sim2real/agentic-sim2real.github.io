# Agentic Diagnosis of Robotic Sim-to-Real Gap

Project page: https://agentic-sim2real.github.io/

A static site (plain HTML, CSS and JavaScript, no build step). `index.html` is the page; `css/`, `js/`, `data/`, `img/` and
`video/` hold its styles, scripts, replay data and clips. Every video is a render of the experiments described in the paper:
MuJoCo for the agent's simulator and Isaac Lab PhysX, rendered in Omniverse, for the target environment.
